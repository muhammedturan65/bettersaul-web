   116→   515→   515→
   117→   516→   516→### Page Breaks
   118→   517→   517→
   119→   518→   518→Follow the document type strategy defined in SOUL.md Rule 1.
   120→   519→   519→
   121→   520→   520→**Structural breaks (always - MANDATORY):**
   122→   521→   521→- Between cover page and TOC - **cover must NEVER share a page with anything else**
   123→   522→   522→- Between TOC and main content
   124→   523→   523→- Between main content and back cover
   125→   524→   524→
   126→   525→   525→**Content breaks (by document type):**
   127→   526→   526→- **Default (all document types)**: ❗ **Absolutely NEVER force page breaks before H1/H2** — content flows naturally, do not insert `PageBreak()` before section headings. This is an iron rule.
   128→   527→   527→- Resume / contract / letter → No content page breaks
   129→   528→   528→- Short article → No content page breaks
   130→   529→   529→- **Exception 1**: Academic papers / textbooks / teaching plans → `PageBreak()` before each H1 is acceptable (only if user explicitly requests academic formatting)
   131→   530→   530→- **Exception 2**: User explicitly requests page breaks between chapters
   132→   531→   531→
   133→   532→   532→**Anti-tear (mandatory — but with height limit):**
   134→   533→   533→```python
   135→   534→   534→from reportlab.platypus import KeepTogether
   136→   535→   535→from reportlab.lib.pagesizes import A4
   137→   536→   536→from reportlab.lib.units import inch
   138→   537→   537→
   139→   538→   538→# Maximum height for KeepTogether blocks: 40% of page height
   140→   539→   539→# Blocks taller than this should NOT be kept together — they cause
   141→   540→   540→# the preceding page to be mostly empty when the block gets pushed down.
   142→   541→   541→MAX_KEEP_HEIGHT = A4[1] * 0.4  # ~336pt ≈ 12cm
   143→   542→   542→
   144→   543→   543→def safe_keep_together(elements):
   145→   544→   544→    """Wrap elements in KeepTogether only if their total height is reasonable.
   146→   545→   545→    If too tall, keep only the FIRST TWO elements together (e.g. title + table/image header)
   147→   546→   546→    to prevent title-content separation, while letting the rest paginate naturally.
   148→   547→   547→    """
   149→   548→   548→    total_h = 0
   150→   549→   549→    for el in elements:
   151→   550→   550→        w, h = el.wrap(A4[0] - 2*inch, A4[1])
   152→   551→   551→        total_h += h
   153→   552→   552→    if total_h <= MAX_KEEP_HEIGHT:
   154→   553→   553→        return [KeepTogether(elements)]
   155→   554→   554→    elif len(elements) >= 2:
   156→   555→   555→        # Keep at least title + first element together to prevent title orphaning
   157→   556→   556→        return [KeepTogether(elements[:2])] + list(elements[2:])
   158→   557→   557→    else:
   159→   558→   558→        return list(elements)
   160→   559→   559→
   161→   560→   560→# Heading stays with first paragraph
   162→   561→   561→story.extend(safe_keep_together([
   163→   562→   562→    heading_paragraph,
   164→   563→   563→    first_body_paragraph,
   165→   564→   564→]))
   166→   565→   565→
   167→   566→   566→# Image + caption: keep together ONLY if image is small
   168→   567→   567→story.extend(safe_keep_together([image, caption_paragraph]))
   169→   568→   568→
   170→   569→   569→# Table title + table: keep together ONLY if table is short
   171→   570→   570→if len(table_data) <= 15:
   172→   571→   571→    story.extend(safe_keep_together([table_title, table]))
   173→   572→   572→else:
   174→   573→   573→    # Long table: just keep title with the table start
   175→   574→   574→    story.extend(safe_keep_together([table_title]))
   176→   575→   575→    story.append(table)
   177→   576→   576→```
   178→   577→   577→
   179→   578→   578→**⚠️ KEY INSIGHT:** `KeepTogether` is the #1 cause of “empty page with chart on next page”.
   180→   579→   579→When a `KeepTogether` block is taller than the remaining space on the current page,
   181→   580→   580→ReportLab pushes the **entire block** to the next page, leaving the current page mostly empty.
   182→   581→   581→**Always use `safe_keep_together()` to cap the maximum block height.**
   183→   582→   582→
   184→   583→   583→**⚠️ Note:** Do NOT use `KeepWithNext` - it is unreliable in ReportLab 4.x.

   187→   586→   586→* Before tables: `Spacer(1, 18)` after preceding text
   188→   587→   587→* After tables: `Spacer(1, 6)` before table caption
   189→   588→   588→* After table captions: `Spacer(1, 18)` before next content
   190→   589→   589→* Between paragraphs: `Spacer(1, 12)` (~1 line)
   191→   590→   590→* Between H3 subsections: `Spacer(1, 12)`

   196→   595→   595→### Cover Page: HTML/Playwright Unified Cover System
   197→   596→   596→
   198→   597→   597→**⚠️ Report route covers are ALWAYS generated via HTML/Playwright**, using the same 5-template system defined in `typesetting/cover.md`. This ensures visual consistency across all routes (Report, Creative, Academic) and avoids the limitations of ReportLab for complex cover layouts.
   199→   598→   598→
   200→   599→   599→**Pipeline (Report route):**
   201→   600→   600→1. Generate **body PDF** via ReportLab (start with TOC or content - **no cover in story[]**)  
   202→   601→   601→2. Generate **cover HTML** following `typesetting/cover.md` 5-template system  
   203→   602→   602→3. **Run `poster_validate.py check-html` on cover HTML** — fix any ERRORs before rendering (overflow:hidden, font fallback, etc.)  
   204→   603→   603→4. **Run `cover_validate.js` on cover HTML** — detects text-vs-decorative-line overlaps. Non-zero exit = must fix before proceeding.
   205→   604→   604→   ```bash
   206→   605→   605→   node "$PDF_SKILL_DIR/scripts/cover_validate.js" cover.html
   207→   606→   606→   ```
   208→   607→   607→5. Render cover HTML → single-page PDF via Playwright (`html2poster.js`) — **NOT `html2pdf-next.js`** (which converts absolute→static and destroys cover layout). **⚠️ MUST pass `--width 794px` for A4 documents** (A4 = 210mm = 794px @96dpi). Without this, `html2poster.js` defaults to 720px (=540pt), which is narrower than A4 (595pt) and causes page size mismatch after merging with the body PDF.  
   209→   608→   608→6. **Merge: insert cover as page 0** of body PDF using pypdf → output single final PDF
   210→   609→   609→
   211→   610→   610→> **Why not ReportLab covers?** ReportLab is excellent for structured content (tables, paragraphs, flowables) but painful for visual design (geometric accents, precise absolute positioning, web fonts). HTML/CSS handles these natively. One cover system, one visual standard, zero inconsistency.

   220→   619→   619→- Business proposals, project plans, feasibility studies
   221→   620→   620→- Technical documentation, product manuals, user guides
   222→   621→   621→- Annual reports, financial summaries, quarterly reviews
   223→   622→   622→- Any formal document ≥ 3 pages that will be shared externally or submitted
   224→   623→   623→

   228→   627→   627→- **Forms / checklists / invoices** - functional documents

   273→   672→   672→    """Render HTML cover to PDF via html2poster.js.
   274→   673→   673→    
   275→   674→   674→    ⚠️ ALWAYS use html2poster.js for covers (NOT html2pdf-next.js).
   276→   675→   675→    Cover HTML uses position:absolute for layout. html2pdf-next.js pre-render
   277→   676→   676→    hooks convert absolute→static to prevent multi-page overlap, which
   278→   677→   677→    destroys cover layouts. html2poster.js preserves absolute positioning.

   287→   686→   686→
   288→   687→   687→**Insertion script (single output PDF):**
   289→   688→   688→```python
   290→   689→   689→from pypdf import PdfReader, PdfWriter
   291→   690→   690→
   292→   691→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   293→   692→   692→
   294→   693→   693→def normalize_page_to_a4(page):
   295→   694→   694→    """Scale a page to A4 if its dimensions don't match."""
   296→   695→   695→    box = page.mediabox
   297→   696→   696→    w, h = float(box.width), float(box.height)
   298→   697→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   299→   698→   698→        page.scale_to(A4_W, A4_H)
   300→   699→   699→    return page
   301→   700→   700→
   302→   701→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   303→   702→   702→    """Insert cover as first page of body PDF → single output file."""
   304→   703→   703→    writer = PdfWriter()
   305→   704→   704→    # Cover as page 1
   306→   705→   705→    cover_page = PdfReader(cover_pdf).pages[0]
   307→   706→   706→    writer.add_page(normalize_page_to_a4(cover_page))
   308→   707→   707→    # Body pages follow
   309→   708→   708→    for page in PdfReader(body_pdf).pages:
   310→   709→   709→        writer.add_page(normalize_page_to_a4(page))
   311→   710→   710→    writer.add_metadata({'/Title': 'Report Title', '/Author': 'Z.ai', '/Creator': 'Z.ai'})
   312→   711→   711→    with open(output_pdf, 'wb') as f:
   313→   712→   712→        writer.write(f)

   367→   766→   766→
   368→   767→   767→### Standard Table Color Scheme (MUST USE for ALL tables)
   369→   768→   768→
   370→   769→   769→> **Colors MUST come from the `palette.cascade` output (Step 2).** The values below are variable names - they are populated by the cascade palette, never hardcoded.
   371→   770→   770→
   372→   771→   771→```python
   373→   772→   772→# Colors from palette.cascade (Step 2) — NEVER hardcode hex values
   374→   773→   773→# Table header uses HEADER_FILL (M tier, S ≤ 0.30) — NOT ACCENT (XS tier, too vivid)
   375→   774→   774→TABLE_HEADER_COLOR = HEADER_FILL          # M tier — low-sat, blends with document body
   376→   775→   775→TABLE_HEADER_TEXT  = colors.white          # White text for header (fixed)
   377→   776→   776→TABLE_ROW_EVEN     = colors.white          # White for even rows
   378→   777→   777→TABLE_ROW_ODD      = TABLE_STRIPE          # L tier — very subtle same-hue stripe
   379→   778→   778→```
   380→   779→   779→
   381→   780→   780→> **⚠️ Why NOT `ACCENT` for table headers?** `ACCENT` is XS tier (S = 0.50-0.75), designed for tiny elements like badges and tags. Table headers occupy 5-20% of visual area (M tier). Using high-saturation `ACCENT` on table headers creates jarring color blocks that clash with the low-saturation body. `HEADER_FILL` (S ≤ 0.30) is specifically designed for this area ratio.

   383→   782→   782→### Table Rules
   384→   783→   783→- Caption must be centered, added immediately after the table
   385→   784→   784→- Entire table must be centered on the page
   386→   785→   785→- **Header Row**: Dark background (from palette `HEADER_FILL`, M tier), white bold text
   387→   786→   786→- **Cell Margins**: Left/Right at least 120-200 twips
   388→   787→   787→- **Alignment**: Each body element within the same table must be aligned the same method
   389→   788→   788→- **Color consistency**: All tables in one PDF must use the same `HEADER_FILL` + `TABLE_STRIPE` scheme
   390→   789→   789→- **Spacing**: `Spacer(1, 18)` → Table → `Spacer(1, 6)` → Caption → `Spacer(1, 18)`
   391→   790→   790→
   392→   791→   791→### Table Centering Enforcement (MANDATORY)
   393→   792→   792→
   394→   793→   793→**Every table MUST be horizontally centered on the page. No exceptions.**
   395→   794→   794→
   396→   795→   795→```python
   397→   796→   796→# ReportLab: ALWAYS set hAlign='CENTER'
   398→   797→   797→table = Table(data, colWidths=col_widths, hAlign='CENTER')
   399→   798→   798→
   400→   799→   799→# Width rule: table total width should be 85-100% of available content width
   401→   800→   800→available_width = doc.width  # or page_width - left_margin - right_margin
   402→   801→   801→table_width = sum(col_widths)
   403→   802→   802→if table_width < available_width * 0.85:
   404→   803→   803→    # Scale up columns proportionally to fill space
   405→   804→   804→    scale = (available_width * 0.90) / table_width
   406→   805→   805→    col_widths = [w * scale for w in col_widths]
   407→   806→   806→
   408→   807→   807→# ❌ WRONG — no hAlign (defaults to LEFT, table drifts left)
   409→   808→   808→table = Table(data, colWidths=[100, 200, 150])
   410→   809→   809→
   411→   810→   810→# ✅ RIGHT — explicit centering
   412→   811→   811→table = Table(data, colWidths=[100, 200, 150], hAlign='CENTER')
   413→   812→   812→```
